# Send Emails

The send endpoints are the core of Dispatch. They accept email requests, render templates, check suppressions, and queue messages for delivery.

---

## Send Transactional Email

Sends a single email using a named template.

```
POST /api/v1/sites/{site}/send
```

### Request

```json
{
  "to": "user@example.com",
  "template": "welcome",
  "data": {
    "name": "Alex",
    "login_url": "https://example.com/login"
  },
  "tags": ["onboarding"],
  "metadata": {
    "user_id": "usr_123",
    "signup_source": "landing-page"
  }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `to` | string | ✅ | Recipient email address |
| `template` | string | ✅ | Template slug (matches filename without `.html`) |
| `data` | object | No | Custom data passed to the template |
| `tags` | array | No | Tags for categorization and filtering |
| `metadata` | object | No | Arbitrary key-value metadata (stored, not sent to recipient) |

### Response (202 Accepted)

```json
{
  "id": "msg_a1b2c3d4e5f6",
  "status": "queued",
  "to": "user@example.com",
  "template": "welcome",
  "site": "my-site",
  "queued_at": "2026-03-14T22:50:00Z"
}
```

### Error Responses

**Template not found (400):**
```json
{
  "error": "TEMPLATE_ERROR",
  "message": "template \"welcome\" not found in sites/my-site/templates",
  "code": "TEMPLATE_ERROR"
}
```

**Recipient suppressed (409):**
```json
{
  "error": "RECIPIENT_SUPPRESSED",
  "message": "Recipient is on the suppression list",
  "code": "RECIPIENT_SUPPRESSED"
}
```

## Send Raw Email (No Template)

Send an email with inline content — no template file needed.

```
POST /api/v1/sites/{site}/send/raw
```

### Request

```json
{
  "to": "user@example.com",
  "subject": "Your order has shipped!",
  "html": "<h1>Shipped!</h1><p>Tracking: {{.Data.tracking_id}}</p>",
  "text": "Shipped! Tracking: {{.Data.tracking_id}}",
  "data": {
    "tracking_id": "1Z999AA10123456784"
  },
  "tags": ["transactional", "shipping"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `to` | string | ✅ | Recipient email address |
| `subject` | string | ✅ | Email subject (supports template variables) |
| `html` | string | ✅ | HTML body (supports template variables) |
| `text` | string | No | Plain text body (auto-generated from HTML if omitted) |
| `data` | object | No | Data for template variable substitution |
| `tags` | array | No | Tags for categorization |
| `metadata` | object | No | Arbitrary metadata |

### Response (202 Accepted)

Same format as the template-based send endpoint.

### When to Use Raw vs Template

| Scenario | Use |
|----------|-----|
| Recurring emails (welcome, reset, digest) | Template-based send |
| One-off emails with dynamic content | Raw send |
| Emails generated by external systems | Raw send |
| A/B testing different content | Raw send |

## Batch Send

Send the same template to multiple recipients with per-recipient data.

```
POST /api/v1/sites/{site}/send/batch
```

### Request

```json
{
  "template": "weekly-digest",
  "recipients": [
    {
      "to": "alice@example.com",
      "data": { "name": "Alice", "items_count": 5 }
    },
    {
      "to": "bob@example.com",
      "data": { "name": "Bob", "items_count": 12 }
    },
    {
      "to": "charlie@example.com",
      "data": { "name": "Charlie", "items_count": 0 }
    }
  ],
  "tags": ["digest", "weekly"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `template` | string | ✅ | Template slug |
| `recipients` | array | ✅ | List of recipient objects |
| `recipients[].to` | string | ✅ | Recipient email |
| `recipients[].data` | object | No | Per-recipient template data |
| `tags` | array | No | Tags applied to all messages in the batch |

### Response (202 Accepted)

```json
{
  "batch_id": "batch_x1y2z3",
  "total": 3,
  "queued": 2,
  "suppressed": 1
}
```

The response tells you how many were queued vs suppressed. Suppressed recipients are silently skipped.

### Batch Limits

| Limit | Value |
|-------|-------|
| Maximum recipients per batch | 1,000 |
| Maximum request body size | 10 MB |

For larger batches, split into multiple requests.

## Delivery Tracking

After sending, track delivery status:

```bash
# Get message details
curl http://localhost:8080/api/v1/messages/msg_a1b2c3d4e5f6 \
  -H "Authorization: Bearer YOUR_KEY"
```

```json
{
  "id": "msg_a1b2c3d4e5f6",
  "site": "my-site",
  "to": "user@example.com",
  "template": "welcome",
  "status": "delivered",
  "backend": "resend",
  "backend_id": "re_xxxxx",
  "queued_at": "2026-03-14T22:50:00Z",
  "sent_at": "2026-03-14T22:50:01Z",
  "delivered_at": "2026-03-14T22:50:03Z"
}
```

### Message Statuses

| Status | Description |
|--------|-------------|
| `queued` | Message created, waiting in queue |
| `sending` | Worker has picked it up, delivery in progress |
| `delivered` | Backend confirmed delivery |
| `bounced` | Recipient's mail server rejected the email |
| `failed` | All retry attempts exhausted |
| `suppressed` | Recipient was on the suppression list (skipped) |

## SDK Examples

### Python

```python
from dispatch import Dispatch

client = Dispatch(host="https://mail.yourdomain.com", api_key="dsp_site_xxx")

# Template send
result = client.send(
    template="welcome",
    to="user@example.com",
    data={"name": "Alex"}
)
print(result.message_id)  # msg_a1b2c3d4e5f6

# Raw send
result = client.send_raw(
    to="user@example.com",
    subject="Your order shipped!",
    html="<h1>Shipped!</h1>",
)

# Batch send
results = client.batch_send(
    template="digest",
    recipients=[
        {"to": "alice@example.com", "data": {"name": "Alice"}},
        {"to": "bob@example.com", "data": {"name": "Bob"}},
    ]
)
```

### Go

```go
client := dispatch.New("https://mail.yourdomain.com", "dsp_site_xxx")

result, err := client.Send(ctx, &dispatch.SendRequest{
    Template: "welcome",
    To:       "user@example.com",
    Data:     map[string]any{"name": "Alex"},
})
```

### cURL

```bash
curl -X POST https://mail.yourdomain.com/api/v1/sites/my-site/send \
  -H "Authorization: Bearer dsp_site_xxx" \
  -H "Content-Type: application/json" \
  -d '{"to":"user@example.com","template":"welcome","data":{"name":"Alex"}}'
```
